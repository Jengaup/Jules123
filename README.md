# Sistema de Contabilidad y Finanzas para Iglesias en Puerto Rico

Este es un sistema simple basado en Flask para administrar la contabilidad y las finanzas de una iglesia en Puerto Rico, teniendo en cuenta las particularidades fiscales locales, como la exención de vivienda para ministros.

## Características

- Registro de ingresos (Diezmos, Ofrendas, etc.)
- Registro de gastos (Servicios, Mantenimiento, etc.)
- Manejo de compensación para ministros (Salario vs. Vivienda)
- Reportes financieros básicos.

## Instalación

1. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```

2. Ejecutar la aplicación:
   ```bash
   python app.py
   ```
